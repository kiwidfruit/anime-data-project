# anime-data-project

Milestone 1- Data analysis project exploring population patterns and variable relationships through visualizations, using structured demographic data and statistical methods.

Milestone 2 - Anime Rating Prediction, machine learning models to predict anime rating while using R² score and compared to determine the best performing model.

Milestone 3- K-Means clustering and a permutation test to analyze anime ratings, popularity, and episode count, while also improving model evaluation with residual analysis and MSE comparisons.
